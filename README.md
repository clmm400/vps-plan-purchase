## 搬瓦工購買前，先確認 VPS 要用來做什麼

VPS 是需要自行管理的虛擬伺服器。搬瓦工官方列出的 KiwiVM 控制面板功能包括開關機、重裝作業系統、緊急主控台、快照、使用量統計與資料中心遷移；官方也明確將服務描述為 self-managed。這代表伺服器開通後，系統更新、服務安裝、網站設定與安全維護等工作通常要由使用者自行處理。

因此，先想清楚主要用途，比先挑最大規格更實際：

- **學 Linux 或測試部署**：先比較入門 KVM 方案的硬碟、記憶體和每月流量，不需要為高階線路或大量資源先付費。
- **架設網站或執行常駐服務**：估算應用程式的記憶體需求、備份方式與流量；網站成長後再考慮升級，比一開始買過大的方案更容易控制成本。
- **重視中國方向的網路連線**：比較 CN2 GIA 電商方案與一般方案，並確認可選機房。路線名稱本身不能保證每個地區、電信商和時段都有相同速度。
- **需要較高規格或服務等級承諾**：才進一步查看 E-Commerce SLA 類方案。其價格與硬體規格明顯高於入門方案，並不是一般測試用途必需。

如果你還沒有 Linux 伺服器管理經驗，也要把維護時間算進去。KiwiVM 可以處理部分主機層面的操作，但它不等於代管服務；需要有人替你配置應用程式或排查網站問題時，應先確認是否符合自管 VPS 的使用方式。

## 優惠碼、付款和退款要注意什麼？

目前查到的官方購物車資料顯示各產品及其公開價格，但不能據此確認某個網路流傳的折扣碼仍有效。不要把第三方文章中過去的促銷碼直接當成現行優惠。結帳時若頁面有折扣欄位，可核對官方當下是否明確提供優惠；沒有可確認的活動，就以購物車最終金額為準。

付款方式也應以結帳頁實際列出的選項為準。不同付款方式可能涉及不同的付款流程或帳戶要求；下單之前先確認幣別、應付總額與訂單內容，付款後保留訂單紀錄。

退款條件則應查看購買時適用的服務條款與方案說明。官方首頁列有 30 天退款政策，但具體適用條件可能依服務和訂單條款而異。若退款權益是你的重要考量，不要只依賴摘要描述，應先讀取對應條款。

## 常見問題

### 搬瓦工購買後可以更換機房嗎？

官方方案說明指出，部分產品支援在資料中心之間遷移，並表示遷移可不造成資料遺失。但可遷移的機房取決於所購方案，不能假設所有套餐都能切換至所有位置；下單前確認該產品列出的資料中心和遷移條件。

### 搬瓦工的 Basic KVM 和 CN2 GIA 電商方案差在哪裡？

兩者規格檔位看起來可能相近，但網路路線、速度標示、可選機房和價格週期不同。應以官方產品描述和實際購物車為準，並按連線需求選擇。若你的用途不依賴特定網路路線，先比較 Basic 方案可能更容易控制支出。

### 新手應該一次買高規格嗎？

通常先按目前工作負載選規格更合理。記錄應用的記憶體、磁碟和流量需求，避免為短期內用不到的容量預先付費。若之後資源不夠，再確認帳戶可用的升級方式與價格。

### 購買搬瓦工是否等於有人幫忙管理伺服器？

不等於。官方將 VPS 定義為自管服務；KiwiVM 提供的是伺服器管理功能，不是代替使用者維護網站或應用程式的託管服務。
